# 🔐 React Authentication Form

A simple and interactive **Login & Signup Form** built with **React.js**.

## ✨ Features

- 🔄 Toggle between Login & Signup
- 🎨 Active tab styling
- 📧 Email & Password fields
- 🔑 Confirm Password field
- 🔗 Forgot Password option
- ⚡ Interactive UI using React `useState`

## 🛠️ Tech Stack

- React.js
- JavaScript
- HTML
- CSS

## 🚀 Run Locally

```bash
npm install
npm run dev
```
