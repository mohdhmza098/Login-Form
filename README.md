## ✨ Features

| Feature | Description |
|---|---|
| 🔄 **Toggle Forms** | Switch between Login and Signup with one click |
| 🎯 **Active Tab Highlight** | Selected tab changes color using dynamic `className` |
| ⚛️ **Conditional Rendering** | Only the selected form is rendered on screen |
| 🎨 **Clean UI** | Centered card layout styled with plain CSS |
| ⚡ **Fast** | Built on Vite for instant hot reload |

---

## 🧠 React Concepts Used

- `useState` for managing which form is active
- Conditional rendering with the ternary operator (`? :`)
- Dynamic `className` based on state
- Event handling with `onClick`
- Component-based structure

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/your-username/react-auth-form.git
```

**2. Go into the project folder**

```bash
cd react-auth-form
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in browser**

```
http://localhost:5173
```
